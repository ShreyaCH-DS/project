# Data Science Project
===

# 

# This repository is part of Assignment 6 for Tools of Data Science. It demonstrates clear file naming, project organization, Git workflows, and Conda environment management.

# 

# The report loads and visualizes a dataset, trains a logistic regression model, and evaluates its accuracy.

# 

# \## Repository structure

# 

# \- `data/`: CSV dataset.

# \- `docs/`: documents, meeting minutes, and PDF report.

# \- `images/`: dataset visualization and prediction plots.

# \- `src/`: Python scripts for generating data and creating plots.

# \- `reports/`: analysis notebook (`report.ipynb`).

# \- `environment.yaml`: Conda environment configuration.

# \- `.gitignore`: rules for excluding temporary files.

# \- `LICENSE`: MIT license.

# 

# \## Environment setup

# 

# With Conda installed, run these commands from the project folder:

# 

# ```bash

# conda env create -f environment.yaml

# conda activate project-env

# ```

# 

# The environment requires Python 3.10 or higher and includes pandas, matplotlib, scikit-learn, and ipykernel.

# 

# With nb\_conda\_kernels installed in the environment running JupyterLab, select the `project-env` kernel to use these packages in a notebook.
